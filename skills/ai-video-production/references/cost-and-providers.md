# 服务、费用与能力适配

## 低成本策略

真实素材从适用的免费许可库/档案/自有素材优先；音乐从已创作的适用作品检索；在本地剪辑、混音、渲染；文案和设计先锁定，配音分段复用。默认不生成 AI 图像、视频或音乐，不购买素材订阅。低成本不以随拍、低清或不贴合的素材替代；免费素材也有许可要求，不能用付费站预览代替原片。

| 能力 | 优先实现 | 换工具的条件 |
|---|---|---|
| 检索事实/原始媒体 | 网页搜索、机构档案、官方发布/媒体包 | 对应题材缺素材时拓展来源 |
| 下载/探测 | 官方下载、授权范围内 yt-dlp、FFprobe | 平台限制则换来源，不绕访问控制 |
| TTS | 已授权供应商；MiniMax、Azure、ElevenLabs、OpenAI 等候选 | 试样合格、目标语言/用量/许可/计费清楚；不固定品牌 |
| ASR/对齐 | 可用的本地 Whisper/其他已授权工具 | 本地不足时先核对外传范围和收费 |
| 音乐 | 已创作且许可适用的器乐/自有音乐，本地节选与重编排 | 用户明确要生成音乐才考虑 Suno 等，核查本轮需求、费用与商业使用条件 |
| 剪辑/字幕/混音 | FFmpeg + 本 Skill 工具 | 复杂版式/运动图形可用 HyperFrames、Remotion 或 NLE |
| 数字人 | 不默认使用 | 用户明确需要才使用 HeyGen 等 |

列出的供应商只是可选能力入口，不构成已安装、已授权或现行价格承诺。选用前查询官方文档和实际账户计费；不要把不存在的模型、套餐或免费额度写进默认配置。

## 费用账本

`costs.json` 的货币和额度属于单个项目。收费动作记录：动作 ID、供应商、文本/输入哈希、模型、费率依据链接与日期、计费单位/预估用量、预留上限、状态、响应 ID、实际或估算金额、invoice_verified。

状态顺序：`reserved`（提交前记账）→`settled`（返回后记录）；错误/未知结果保留 reserved，查供应商任务/账单后再结算或明确取消。不能以客户端超时当作免费失败然后重发。实际发起网络请求由授权的工具完成，账本不替代授权。

`reserve` 拒绝超额、重复 ID、同一输入已存在待计费动作。`settle` 仅结算已有预留；金额若高于预留记录超额事实并停止新动作，不能隐藏实际支出。账本更新有独占锁与原子写入。不存在发票就将金额标估算，不编造“已扣费”。

所有支出包括试音、修正、重试、导出、素材与新订阅；报价用原币，换算人民币时查汇率并说明。没有发票/后台明细不能给出虚假的精确累计成本。费用未知先暂停受影响的收费步骤，继续免费准备。

## 隐私与密钥

用环境变量或系统秘密存储，不把值打印到日志、写入 JSON、复制进 Skill/仓库。服务仅接收完成本次授权必要的数据；云端上传与本地处理分开写明。私人音色/人像克隆需要对象授权，不由拥有文件推定。
