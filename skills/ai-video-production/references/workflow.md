# 端到端工作流

## 输入与合理默认

一句“做一个航天史视频”已经是执行请求。读取已有偏好，补足能自行判断的参数，把假设写到简报；不要交付一份建议然后停下。

| 字段 | 处理方法 |
|---|---|
| 核心问题 | 这支片子解释什么变化，让观众理解什么；不是堆关键词 |
| 观众/发布场景 | 决定解释深度、语速、字号与交付画幅 |
| 信息截止时间 | 含时区；“最新/今天”每次核查，不继承旧项目日期 |
| 长度 | 按内容确定；未指定可从约 4–6 分钟设计，不能删掉关键因果来凑时长 |
| 语言/字幕 | 默认英文旁白、中上英下，可完全配置 |
| 预算 | 区分已授权上限、已用、待计费、未知结果；没有新授权不能沿用别的项目额度 |
| 交付 | 默认完整成片与工程说明；只要试音时不提前生成整片 |

## 独立工程与状态

`init` 创建 `brief.json`、`project.json`、`state.json`、素材/音轨/工作/交付目录。具体隐私工程应在仓库外。保存内容：

```text
project.json       # 主时间线、事实、素材、字幕、音乐计划、音轨与技术配置
state.json         # 当前请求、阶段、已验证结果、未完成项、阻碍、唯一执行者
costs.json         # 每次可计费动作；先登记再调用
assets/            # 本地授权素材，按来源与类型分类
audio/             # 旁白、现场音、音乐、分轨、最终混音
work/              # 探测、代理、预览、帧检查、缓存，保留恢复能力
deliverables/      # MP4、字幕、说明、报告，旧版本保留
```

## 七步执行

先读取 [通用质量标准](quality-bar.md)。用户有脚本时，核查事实与时长，提取画面/配乐意图，再选择真实材料；具体配色、人物呈现和时长只写入当前简报。

1. **事实结构**：研究问题→一手证据→大纲→逐字稿。先写“发生什么、为何发生、机制是什么、改变什么”，再写有力量的表达。产出 `facts` 与 `beats`，每个叙事单元有素材检索方向。
2. **素材预选**：每个重要节点必须找到能说明该节点的具体画面。至少跨官方/档案/实拍库等合适类别检索；拓展来源服务内容，不为数量生硬加素材。下载原文件、记录来源和许可、探测编码/有效尺寸、查看首中尾。
3. **剪辑设计**：画面围绕句子的核心名词、动作、论点配置。为每一对相邻镜头写前后关系；数据/机制说明按 [辅助说明规则](explanatory-visuals.md) 检索、计算、授权和设计，静态图也要有完整可读的信息；配乐情绪图与镜头设计同步。技术不可信的片段、无关隐喻、首页替代发布会在这里淘汰。
4. **声音定稿**：新声线先短样；语言改变必须重听该语言试样。付费前确认已选声线、断句、专名、价格和额度。分段生成，记录哈希与任务状态。检查识别结果及真实音频；个别错误只重做对应段。
5. **以音定时**：最终配音/原声时间决定时间线。由 ASR/强制对齐得到时点，但字幕显示使用校对过的文案。翻译不机械追逐单词，按语义分组。把原声窗口、沉默与结尾音乐尾声留到主时间线上。
6. **预览到全片**：预览开头、年代/场景转换、产品演示、原话、最复杂字幕、结尾等关键段。修复根因后一次全片导出。镜头/源文件/字幕/音频/参数变化使相关缓存失效，转场缓存同时依赖左右镜头。必要检查通过后不无限重渲染。
7. **播放与交接**：检查导出解码、帧数、音轨、色彩、字幕与响度；实际播放检查转场、口型/原话、字幕与听感；生成交付报告，区分机器通过、人工通过、未审阅、用户验收。

## 修改现有成片

先写修改范围。如仅换声线与配乐：尽可能保留接受的画面；新音轨改变句长时局部调整时点，不能生搬原语言时间线。更改镜头时同时检查前后边界与 BGM 触发点。保留旧版，记录变更与实际验证。

## 工具选择

FFmpeg 是默认本地剪辑/混音/编码底座，运行脚本只依赖 Python 标准库。ASR、TTS、下载、视觉检查使用环境中已授权可用的工具。简单实拍片不强制 HyperFrames；图表/运动排版才考虑它或 Remotion。HeyGen 只在用户需要数字人时使用。默认不启用视频或音乐生成服务，图片生成仅在用户允许的说明图分支使用；Suno 等只有用户明确需要生成音乐、许可与费用都符合时才用。

没有 API 或遇下载限制时，使用允许的网页操作/官方媒体下载入口/其他素材。不能为了自动化加入证书、代理、私人 Cookie，绕过 DRM 或把私人资料交给陌生服务。

FFmpeg：[官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)。授权范围内获取媒体可用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)；下载工具不授予再利用权，仓库不捆绑二进制。
