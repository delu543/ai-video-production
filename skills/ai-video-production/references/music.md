# BGM：统一调性、叙事起伏与声音平衡

## 先作音乐设计，后调音量

先写 `music_plan`：全片声音世界（音色、节拍、调性感觉、能量范围）、段落情绪、具体触发点、主声部、呼吸/原声窗口、主题再现与结束方式。曲目名字不是情绪设计。

示例情绪路径：开头好奇→探索轻推进→突破增加层次→失败/限制减薄→人的处境温暖而克制→结尾开阔但未完成。不是固定每部片都用这条曲线；判断旁白实际表达，疑问段不能配胜利高潮，技术解释不能被史诗鼓点催赶。

## 声音先分层，再定位问题

区分旁白、真实同期声/原话、后期环境声/拟音和BGM。对“机械音、突兀声、电子感太强”的反馈，定位实际时间码，单独检查各分轨/源文件及交叉区间，判断来自原曲配器、循环点、节拍、混音抽吸、设备声还是拟音。不能靠把整个混音压低解决音色情绪不合，也不能把合理的钥匙、纸张、脚步和空间声一并删掉。

保留有画面或叙事依据的声音细节，控制同步、尾音与音量；没有依据的whoosh、警报、爆炸、故障、点击等装饰声音删去。真实机器工作声在对应实拍中可以有价值，不能因“机械音”一词机械禁用。后期补入的拟音、库环境声单独登记来源与许可，不宣称为画面同期声；它们不能伪造采访、事件或某个真实个案。

## 选曲与结构

- 默认检索已创作且许可适用的真实配乐，入口见 [来源地图](source-catalog.md)。用户给出名曲/作曲家参考时提取乐器、情绪、速度、密度与递进结构，找相近作品；不直接取商业原录音，不自动调用音乐生成模型。
- 全片统一音色与情绪语汇，可用同一作品不同段、兼容的少量作品、主题动机的再现。来自同一作者只是筛选线索，不保证和声/节拍匹配。
- 旁白主导的科普/分析片优先自然、稀疏、不过度催促的器乐质感。检查所用片段中的合成器脉冲、规律机械敲击、高频电子声、低频轰鸣、突发打击与人声纹理是否抢解释。题材是科技不等于要赛博音乐；反馈音色不合时换曲/选段/配器，而非只减总音量。钢琴、原声等是候选方向，不是所有影片的固定配乐；电子音乐只有符合简报和实际内容时才采用。
- 避免在纪录片、恐怖悬疑、游戏赛博与预告片轰鸣之间乱跳。有意对比必须由内容解释，并设计过渡。
- 检查音质、混音密度、旋律是否争抢语言、调性/节拍是否兼容、许可与 Content ID。选择有空间的器乐；默认不用歌词覆盖旁白。
- 按完整乐句剪辑，在节拍/和声落点换段。入出点远离突兀的半个鼓/音头；曲目末尾长静音先检查并去除，不能把静音混成音乐断层。
- 曲间交叉通常可从 2–4 秒试起，但两曲和声不兼容时不能只延长叠加。改入点、找过门、先减薄或留安静窗口；避免两组鼓同时打架。
- 允许同一主题多次回归，但不要机械循环到观众听出重复。音量变化之外还应变化配器密度、段落、节奏、音域和留白。

听实际选用的段落并校准其响度，而非用整曲平均值或标签代替。保存作品、源入出点、选用理由和包络；同一首的安静段与高潮段可能需要不同增益。画面动作、镜头长度和切点随乐句与叙事一起调整，不把音乐最后随意铺在已定的硬切上。

## 有意不配乐

不要求BGM贯穿全片。先在音乐计划写出 **无配乐窗口的起止和内容理由**，再编排音乐cue：开场提问、密集假设/算式、法条、关键结果、原话、生活反思和最后收束，都可以只留人声与合适的环境声。必要时留整个解释段，不只在刺激性数字上挖一个短静音洞；条件、正反情景和限制也要让观众听清。

无配乐不等于总音轨静音。保持旁白连续与自然空间感，不突然把环境底噪截断；该保留的细节继续按画面作用存在。音乐前后进入/退出写明触发点，用完整乐句、自然尾音或适度淡化承接，避免突然起响、循环接缝、抽吸和不相容的双曲叠加。留白之后回归有意义的主题，而非到计时器某个固定秒数就恢复音乐。

记录覆盖时长与分布用于检查是否满铺/是否解释段过密，但不规定全片必须一半无乐、固定三首曲或固定静音秒数。最终比较工程计划与音乐分轨：无乐区间确实没有漏进来的旧曲/混响尾巴；有乐区间保留合理存在感。CLI只按cue混音，不自动决定留白或验证听感。

## 自动化与声音层级

通常层级：需要理解的旁白/真人原话→关键现场声音→BGM→装饰音效。默认宁小勿大，不盖字尾；同时通过编配、乐句和无旁白窗口维持音乐存在感。不能为了稳妥把全片音乐压到几乎不存在，也不能靠抬高总音量制造情绪。

| 窗口 | 处理 |
|---|---|
| 普通解释 | 音乐保持支撑，人声稳定、字尾可辨；关注音乐中频是否遮挡 |
| 密集术语/数字/法律 | 减薄配器或整段撤BGM；假设、否定与限制同样可辨，读数留时间 |
| 原话/现场演示 | 音乐提前约 0.2–0.5 秒退下，原声完整进入；结束后约 0.5–1.5 秒平缓恢复 |
| 无旁白建立场景 | 音乐/环境声可适度上升，但不能突然轰响 |
| 失败/反思 | 不机械升压；可降低能量、留呼吸、改变织体 |
| 结尾 | 由内容产生升华；可在最后几句话前撤主旋律，只留人声/环境声；不必作励志高潮 |

优先手工叙事自动化；可辅以 sidechain ducking，防抽吸、每句都一收一放。`mix` 的节点以每段音频开始后秒数计，跨段自动化由设计者明确写入，不会自动理解情绪。

## 量化起点与实际听感

网络立体声成片可从约 **−16 LUFS、true peak ≤−1.5 dBTP** 设计，编码前可留至 −2 dBTP；平台有要求时覆盖。LRA 不设跨题材万能值；旁白主导片适度动态，同时保留音乐呼吸。

旁白窗口 BGM 常需要比人声低约 16–24 dB，按同一窗口的 RMS/短时响度观察，并实际听辨。不是把原始 BGM 文件统一 −6dB 就算完成；原曲响度不同，频谱遮蔽也不同。音乐的主观存在感由音色、密度和频谱共同决定。

保留独立人声/现场/BGM 分轨和实际cue，检查峰值、整体及段落响度。记录比较窗口、语音活跃条件及测量方法；全片平均响度、ASR、曲目乐器标签或波形不能证明情绪适合、语音自然或音乐不盖声。二遍 loudnorm 后检查最终 AAC 真峰值，编码可能增加峰值。耳机、笔记本扬声器与低音量播放均应能听清旁白；若不能实际听，不声称已听感验收。

编码前通过不代表交付文件通过。压缩后峰值超标时，针对最终编码保留更多余量、重新测量；只是增益/峰值修正且画面已通过，可复用画面码流再封装，保留旧版，不重配音或重剪。修正后复查实际输出响度、峰值、时长与播放，保持旁白/BGM相对平衡。固定的某次减益数值不是通用配方。

## 配乐局部修订

画面、旁白和字幕已接受时，锁定这些部分，只改问题音乐/自动化。沿用既有人声，不重新付费配音；保留用户接受的同期声与拟音cue，不因换曲删除全部声音细节。另存主工程、音乐计划、分轨、混音与MP4，原版保留。换曲后同时更新许可台账、使用时间码、尾页署名和发布说明，不能让新音轨搭配旧曲署名。

导出与复查范围见 [交付细则](delivery.md)：可复用画面码流，尾页因署名变化可局部重编码；核查正文画面保持一致、完整帧轴、最终音轨和变动区间。无法实际听辨时标未审阅并交付试听版本，不把客观数值通过写成完整听审通过。

FFmpeg 二遍 loudnorm、afade、amix、volume、sidechaincompress 等详见 [官方滤镜](https://ffmpeg.org/ffmpeg-filters.html)。本地工具不会自动调用音乐生成服务。
