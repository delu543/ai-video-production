# 跨题材的制作质量标准

适用于历史、科普、科技、品牌与产品视频。先按本标准选材料，再按项目简报决定色彩、时代感、人物呈现和音乐风格。“纪录片与现代宣传片的质感”指可信的内容、专业影像和完整视听设计，不要求所有题材长成同一种片子。

## 真实素材与专业制作同时成立

默认画面来自真实拍摄、原始档案、有出处的摄影或文献，配乐来自已创作且许可适用的作品；不调用生成视频或AI音乐。生成图片仅按 [辅助说明图规则](explanatory-visuals.md) 在用户允许、真实材料无法完成具体数据/机制说明时使用；不能用空泛概念照片补生活画面。AI 配音可在授权范围内使用。用户明确要求生成媒体时另按其范围处理，不把工具权限或预算许可当作生成媒体的需求。

真实性、制作质量、语义对应、使用权是四个独立条件。官方发布、纪录片、专业新闻、机构馆藏和摄影师原片是优先检索方向，来源名称本身不保证每个镜头合格。

| 判断维度 | 在原文件和实际剪辑里看什么 |
|---|---|
| 拍摄与构图 | 主体明确、景别有目的、视线和动作可读；摄影机运动受控，光线有层次，曝光与焦点适合表达 |
| 有效画质 | 真实细节、运动时的压缩、噪点、失焦和裁后显示效果；不能只看下载标签、像素数或截图 |
| 视觉风格 | 色彩、光线、媒介和节奏能融入全片；统一调色不能把随拍变成专业摄影 |
| 证据价值 | 确实是讲到的人物、物件、版本、过程或事件；拍摄时间与所述年代对应，必要限定可读 |
| 声音与动作 | 原声可辨、动作完整，截取后不失去意义；为转场和原话预留头尾余量 |

日常随手拍、低质二次剪辑、下载预览、被反复压缩的转载、水印或播放器录屏，不用来填充成片。4K 标签也不能豁免。专业纪录片的手持镜头、新闻现场的必要运动可以成立，不能把“手持”本身当作不专业。

## 历史记录的例外与照片的选择

稀缺的原始讲话、采访、事件录像或馆藏照片，可能不是高清。先找较好的原片、馆藏扫描或可信修复版，再按记录价值和实际显示效果决定；标明原始媒介、年代和质量限制。不得把现代低质素材伪装成档案、加颗粒遮掩缺陷，或宣称放大增加了真实细节。

优质照片、实物摄影和原始文献可以优于模糊视频或无关库存。用有目的的局部特写、缓慢推拉、镜头衔接与原声融入，不制造假现场，也不做逐页图片轮播。视频优先是选材倾向，不是跨题材统一的比例指标。

人物身份、照片年代和场景必须回到原始条目核对。多人合照不凭文件名认人，后年采访不冒充当年录像，现代示意不冒充历史现场。取文件还要核对实际类型：HTTP 成功或 `.jpg` 后缀不保证返回的是图片，而非登录/错误 HTML。

## 把脚本要求转成可以制作的意图

用户给出画面或音乐参考时，提取其作用：对象、动作、信息、情绪、节奏与转折。找最贴近这些意图的真实视频、照片和授权配乐，剪法可按叙事调整；不用参考里的“生成”“漂浮”“碎裂”等字眼自动启用生成模型。需要说明机制时可用准确的计算录屏、图表或文字排版；允许的生成说明图必须表达数据与关系，达到全片质感，不能以廉价排版、裁半的数字或无文字背景凑合。

参考的固定配色、每镜秒数、人物只拍背影、特定乐器和名曲名称，属于项目艺术选择。未被当前用户指定时不套给后续项目。音乐参考用于描述音色、能量、递进与留白，不表示允许直接使用该录音或模仿其旋律。

## 锁定前的四个问题

1. 这个素材在这一句旁白里证明或推进什么，是否比替补更贴切？
2. 在最终构图和播放尺寸下，拍摄质量和证据是否仍然成立？
3. 前后镜头、现场声和音乐是否能形成自然的观看过程？
4. 来源、身份、年代、取得方式和适用许可是否有记录？

任一条件不足，先拓展来源或换高质量照片/等价证据；不为凑数量、凑时长或省一次搜索降低标准。具体操作见 [素材检索](sourcing.md)、[来源地图](source-catalog.md)、[镜头设计](picture.md) 和 [交付验收](delivery.md)。
