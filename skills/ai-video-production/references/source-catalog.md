# 素材检索入口与取用方法

这是检索地图，不是永久免费/可发布清单。选择与题材相关的入口，逐条回到内容页核对作者、原尺寸、许可与日期。网站条件会变；每个项目重新核对，搜索失败就换入口。图库也可能包含 AI 内容，必须筛选真实摄影。

## 真实实拍与照片

| 入口 | 找什么 / 如何取得高质量 | 权利检查 |
|---|---|---|
| [Pexels 视频](https://www.pexels.com/videos/) / [照片](https://www.pexels.com/) | 人、工作、城市、自然等实拍；进入单条页面选原尺寸而非预览 | [Pexels License](https://www.pexels.com/license/)；人物/商标与禁止用途另看条款 |
| [Pixabay 视频](https://pixabay.com/videos/) / [照片](https://pixabay.com/) | 实拍环境、细节、照片；避开生成内容和赞助结果 | [许可摘要](https://pixabay.com/service/license-summary/)；逐条作者与内容检查 |
| [Mixkit](https://mixkit.co/free-stock-video/) | 场景与动作；下载实际 HD/4K 项目文件 | [许可](https://mixkit.co/license/) 区分 Video Free 与 Video Restricted，不混用 |
| [Coverr](https://coverr.co/) | 环境/工作/生活实拍；原片与适用尺寸 | [许可](https://coverr.co/license/)；不要把其 AI 工具输出混入真实素材 |
| [Videezy](https://www.videezy.com/) / [Mazwai](https://mazwai.com/) | 拓展摄影风格与题材，核对具体条目的下载版本 | 不承诺统一许可；确认单条署名、免费/付费与商用条件 |
| [Unsplash](https://unsplash.com/) | 真实摄影补充；原图用于关键静态信息与氛围 | [许可](https://unsplash.com/license) 与人物/商标限制，不能代替实际事件证据 |

## 档案、公共机构与原始记录

| 入口 | 适用内容 / 操作 | 权利与真实性 |
|---|---|---|
| [NASA Image and Video Library](https://images.nasa.gov/) | 科学、航天、实验实拍；找条目原资源而非网页图 | [使用指南](https://www.nasa.gov/nasa-brand-center/images-and-media/)；第三方素材、标识与人物另核查 |
| [Library of Congress](https://www.loc.gov/) | 历史影像/照片/录音；可从 [Free to Use](https://www.loc.gov/free-to-use/) 与馆藏条目开始 | 逐条看 Rights & Access；合集标签不能替代条目审核 |
| [美国国家档案馆](https://www.archives.gov/research/motion-pictures) | 历史运动影像、原始事件；目录→条目→可用数字文件 | 权利与来源逐条确认，不能认定所有美国档案均可随意使用 |
| [DVIDS](https://www.dvidshub.net/) | 联邦机构现场记录、救援/工业/训练等；找原分辨率 | [限制说明](https://www.dvidshub.net/about/copyright)；部分第三方权利可能存在 |
| [Wikimedia Commons](https://commons.wikimedia.org/) | 人物、历史照片、地图、档案影像；打开文件页取 original file | [再利用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)；逐文件许可证、作者与署名 |
| [Europeana](https://www.europeana.eu/) | 欧洲文化与历史档案；过滤媒体和使用条件，回到馆藏原文件 | [再利用说明](https://www.europeana.eu/en/faq)；逐项 rights statement |
| [Internet Archive](https://archive.org/) | 早期影像/纪录片/采访的检索；查上传者、来源、原始文件 | 托管不等于许可，追到原始机构；不下载未经授权的电影/综艺 |
| [Smithsonian Open Access](https://www.si.edu/openaccess) | 物件、发明、文化与历史照片；进入馆藏条目核对标记 | 只使用符合目标用途的具体开放资产，第三方权利仍单独检查 |
| [Computer History Museum](https://computerhistory.org/) | 计算机人物、口述史、展品和事件；馆藏/官方频道查原始记录 | 研究入口；实际视频与馆藏重用需核对相关条目/许可 |

## 官方事件、采访、新闻与授权库

| 入口 | 找素材的方法 | 注意 |
|---|---|---|
| 题材相关公司/大学/机构的官网、press/media 页面 | 原始发布、实验、产品宣传片、媒体包；按实际版本/事件日期搜索 | 官网可读不等于图片/视频自由使用，保存具体使用依据 |
| [YouTube](https://www.youtube.com/) 官方频道与事件录像 | 找完整发布会/访谈/演示，用章节/字幕定位，核对前后语境，取核心少量片段 | 原视频来源优先；清晰度、取得方式与使用权分别确认；不能用首页替代演示 |
| [British Pathé](https://www.britishpathe.com/) | 历史新闻影像的检索与授权原版 | [许可入口](https://www.britishpathe.com/licensing/)，通常需要授权报价，不能下载水印预览当成免费素材 |
| [AP Archive](https://www.aparchive.com/) / [Reuters Connect](https://www.reutersconnect.com/) | 当年事件、人物与新闻原始视频，查具体画面与采访 | 授权入口；默认不新增购买，预算允许且用户授权才采购 |
| 电影/电视/综艺权利方与官方媒体包 | 只在内容确有必要时寻找相关实拍或原话，优先可授权的片段 | 没有“截几秒就免费”规则；有授权才使用，不把片段上传到仓库 |

## 音乐与现场声音

| 入口 | 用途 | 核查 |
|---|---|---|
| [Mixkit 音乐](https://mixkit.co/free-stock-music/) / [音效](https://mixkit.co/free-sound-effects/) | 兼容的器乐、少量环境/过门；完整听曲和尾部 | [对应许可](https://mixkit.co/license/)，具体媒体用途限制与来源留档 |
| [Pixabay Music](https://pixabay.com/music/) | 备选统一调性的音乐，下载完整版本与证明 | [FAQ](https://pixabay.com/service/faq/)；Content ID 登记可能产生认领，保存许可/证书，不能保证“不会被认领” |
| [YouTube Audio Library](https://support.google.com/youtube/answer/3376882) | 可用音乐/音效；按曲目条件选择 | 具体署名与使用规则，不推断对任何外部平台无限授权 |
| [Freesound](https://freesound.org/) | 精确环境/机械音效 | 单条许可不同，注意 CC0/CC BY/NC；禁止用不相干音效假冒真实现场 |
| 原始采访/事件音轨 | 真人原话、现场空间与交互反馈 | 与画面一并核对上下文和许可，原音不由 AI 重演 |

## 搜索记录

保存重要查询、候选原链接、选/弃理由与下载规格。找不到合格视频时，先扩展语言、机构档案与原发布者，再考虑高质量照片。源数量不等于质量：目标是每个叙事单元有最贴切、最清晰的证据。
