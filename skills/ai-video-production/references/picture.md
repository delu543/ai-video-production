# 画面、镜头逻辑与转场

## 每个镜头有任务

在 `shots` 写 `beat_id / purpose / asset_id / source_in / duration / framing / transition`。`purpose` 明确说明当前画面证明、解释或承接什么。逐句对照旁白：说人物就有该人物/相关记录，说功能就有实际操作，说变化就有前后证据。

不允许用无关精美实拍蒙混。人群、眼睛、键盘、实验室等隐喻只能少量补充；科学实验不是所有技术的通用替身。镜头的节奏由信息变化与动作决定，不按固定秒数平均切。

脚本中的画面参考先转成“对象/动作/证据/情绪”的任务，再找最贴近的真实材料。只有确实对应机制的传统图表、排版与轻微照片运动才补入；不能因脚本描述了漂浮、碎裂或光点，就改用生成镜头。全片配色、胶片颗粒、是否露人物正脸与每镜秒数按简报决定。

## 相邻镜头先有逻辑

每个边界写 `relation`，至少一种明确关系：同一事件的连续动作、同一主体的全景到细节、问题到机制、原因到结果、过去到现在、对比、叙事回环、明确章节/年代转换。

例：“手翻纸质账本→同一种记录的计算机终端”通过记录行为推进；“宏观工厂→其中一个操作细节”通过空间推进。“孩童玩耍→芯片特写”若文案未建立联系，不能靠淡化补救，应重选镜头或增加有意义的桥梁。

提前看左右至少数秒并带声音：运动方向、视线、色温、景别、对象位置与声音能否衔接？观众是否知道为什么到下一个场景？必要时放建立空间/对象的桥接镜头。

把音乐乐句、现场动作和旁白转折同时写进切点。配乐推进可以带动画面节奏；事实密集或原话出现时，允许镜头更稳、更长，不为了每3–5秒一切破坏完整动作和理解。远隔的年代/地点不能仅靠短叠化伪装成同一现场。

## 选择切换方式

以下时长是 30fps 下的设计起点，按镜头与节奏调，非全片硬规则。

| 方式 | 使用条件 | 感觉/注意点 |
|---|---|---|
| 有理由的直接切 | 同一记录的动作连续、明确细节/信息推进、真实演示需要完整辨识 | 落在动作/语义/乐句上；没有逻辑的硬切淘汰；记录 `cut_reason` |
| 短交叉淡化约 0.25–0.45s | 同一主题不同场景、轻微空间转换 | 先看叠帧，防双人脸/双文字；不是模糊所有边界 |
| 中交叉淡化约 0.5–0.8s | 年代迁移、档案到现代、反思段落 | 配合内容和声桥；不让产品 UI 两层混在一起 |
| 淡入/淡出约 0.6–1.2s | 开头进入、结尾余韵、明确章节呼吸 | 少用黑场，不每换素材先黑一下；结尾音乐尾音自然落完 |
| 匹配切/动作切 | 构图、对象、动作有真实对应 | 为叙事服务，不能只是炫技；复杂部分用专用剪辑工具 |
| J-cut / L-cut 声桥 | 新场景的现场声先到，或前一句原话延续到后画面 | 可从约 0.2–1s 试起；原话需保留上下文，不能改变说话人意思 |

转场要源片余量。源入点/出点预留对应 handle；中心切点处的淡化覆盖左右镜头，不挤压旁白或移动章节时点。素材不足先改入点或镜头，不默认循环或冻帧。相邻淡化不得互相挤入同一个短镜头。

## 全幅质感

- 1920×1080 默认全幅，主体层级清晰，不加上下黑色/深色条状遮罩。用光线、构图、色彩、运动与留白形成质感。
- 避免廉价 3D、夸张泛光、满屏颗粒、故障特效与繁复动效。不同题材有自己的视觉体系，不能照搬参考截图。
- 标题只在真正需要处出现，建立固定字号/边距/位置/动画节奏；出现和退场可短淡化，不压过主体。减少同时显示的文字与数字，检查所有字幕层，禁止重复叠字。
- 档案 4:3/竖屏保内容置入全幅，柔化背景不出现可读的重复文字/双人像；保留照片主体，不盲目裁头、裁证据、裁产品 UI。
- 静态照片可有克制缓推、平移、视差，但移动有目的且不制造假现场；长文献用关键区域局部特写，保留出处。照片仅在真实信息优于视频时使用，不能做图片轮播。
- 先清理源内非内容黑边，再按实际像素构图；HDR/SDR 做正确色彩转换，不能直接套 BT.709 标签冒充转换。历史胶片与现代影像温和统一，保留不同媒介的真实性。

## 动态验收

每个新素材看首/中/尾和裁切之后的画面；每个镜头边界看移动预览。检查：突跳、叠字、双脸、冻结、黑帧、拉伸、UI 被挡、意外露出播放器、叠帧时旧字幕仍在、淡化中速度不自然。

机器可检查帧数/尺寸/时长/源越界，不能证明镜头逻辑成立。联系表是筛查工具，不能代替带声播放。
