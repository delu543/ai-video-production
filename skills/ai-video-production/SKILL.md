# AI 视频制作

版本：0.1.4。把用户的需求推进到完整视频；用户明确只要试音、设计或某一步时，交付对应阶段。

## 开始执行

1. 识别最新未处理要求、已确认偏好、已有成片/素材/工程、预算和本轮交付。插入问题不替代主任务；接受的部分不重做。只修改配乐时走 [局部修订](references/workflow.md#修改现有成片)，保留合适的声音细节与既有旁白。读取项目状态，检查实际进程，避免重复配音收费或并行写同一工程。
2. 读取 [workflow.md](references/workflow.md)。新片且没有可复用工程时，用 `scripts/video.py init <项目目录>` 建立独立工程；修改现有影片沿用当前工程并另存修订版，不重新初始化无关流程。工具位置相对于本 Skill；项目路径由本轮环境选择。先 `doctor` 核实可用能力，复用成熟工具，不默认安装、订阅或绑定某个平台。
3. 在 `brief.json` 写清题材、受众、信息截止时间、语言、长度、画幅、风格、交付、预算、禁用项。可以判断的常规选择直接决定；仅问会实质改变结果且无法查证的问题。缺少可计费授权时预算为零，先做免费准备。
4. 选材前读取 [quality-bar.md](references/quality-bar.md)，区分通用质量标准与当前脚本的艺术选择，再执行下表阶段门。先把设计和素材匹配做实，再生成整段配音与最终渲染。阶段门是内部检查，不是每一步向用户索取确认。

## 默认制作方向

- 高质量纪录片的事实和影像可信度，加现代科普/宣传片的清晰节奏。讲解自然、年轻、稳，不卖弄庄严，也不轻佻。
- 默认只用真实实拍、历史档案、实际产品演示、有来源的照片与已创作的授权配乐，不调用生成视频或 AI 音乐；AI 配音可用。生成图片仅在用户允许、真实材料无法完成具体数据/机制说明时，作为有信息的辅助说明图使用，见 [explanatory-visuals.md](references/explanatory-visuals.md)。生活场景仍用实拍。视频优先，优质照片可替代不合格视频。拒绝随拍、低质转载与预览填充；真实历史记录按证据价值保留必要例外。
- 横屏默认 1920×1080、30fps、全幅构图；不加上下黑条制造“电影感”。画幅、帧率可按平台调整，不能把低清放大当成高清。
- 本工作流的默认旁白为英文；面向中文观众时中文在上、英文在下。用户指定其他语言/顺序立即覆盖。声线不绑定供应商或某个试音编号。
- 同一素材默认最多使用两次，且间隔疏、用途不同。最新节点使用真实发布/演示内容，不能用官网首页代替事件。
- 配乐先统一音色与情绪逻辑，再做动态和混音；讲解片优先自然、稀疏的音色，不默认铺强电子脉冲。宁小勿大，密集事实、数字、法律与收束可整段无配乐，音乐回归要有理由。保留有画面依据的同期声/拟音，排查突兀机械音时先辨别声音来自哪一层。剪辑节奏与乐句、动作和叙事转折一起设计，详见 [音乐与混音](references/music.md)。
- 默认本地成片交付；对外发布、购买订阅、超预算调用和上传私人资料必须属于本轮有效授权。

## 工具与执行接口

`python3 scripts/video.py --help` 提供 `doctor / init / check / captions / mix / render / qa / reserve / settle`。

- `assets/project.example.json` 是唯一时间线格式示例；各工具读取同一份工程，避免音画各自维护重复状态。
- `check --stage design` 检查来源、字幕、镜头关系、复用和预算；`--stage render` 增加实际文件探测与时长检查；`--stage publish` 额外检查再利用许可。机器检查不能判断画面是否真的贴合某句话，必须人工/视觉审阅。
- `mix` 接受已制作的人声、现场原声和授权配乐，按增益包络/淡入淡出混音，二次响度归一。它不替你选音乐，也不自动生成配音。
- `render` 支持视频、照片、全幅/保内容构图、相邻淡化、已有音频和 ASS 字幕。复杂运动图形可另用 FFmpeg、HyperFrames、Remotion 或剪辑软件；按题材选择，保持工程契约和同样的验收。
- 必须保持镜头总帧数、字幕时间和混音时间一致。没有源视频转场余量时重新选入点，不能默认循环、加速或冻结掩盖缺素材。
- 付费请求前 `reserve` 记录意图与上限，返回后 `settle` 记录用量/金额。结果未知先查任务状态，不能自动再付一次。这个账本不发送请求，供应商仍需相应有效授权。

## 异常与完成边界

缺原片：拓展来源→换高质量相关镜头/照片→必要时明示历史档案例外。不能用网页截图、低清预览或无关实验室填充。

费用/许可/服务阻碍只暂停依赖步骤；继续脚本、免费素材与设计。每次续接更新 `state.json`，记录已验证结果、唯一责任人、未完成项、阻碍和下一动作。不得把旧历史请求重放。

最终至少交付可播放 MP4、字幕、文案/分镜、来源与许可记录、成本账本及技术/视听验收状态。可编辑工程默认保留本地；第三方原素材仅在许可允许的范围交接。不要把“已导出”说成“已逐秒看听并获用户验收”。
