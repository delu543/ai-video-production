# 架构与适配边界

## 四层职责

1. **Agent**：理解简报、核查事实、查找合适素材、写文案、选择声音、设计镜头/音乐、执行主观审阅。艺术判断与授权判断不能交给一份 JSON 代替。
2. **Skill**：阶段门与制作规范。核心入口简短，细节按职责分文件；不把一个影片的题材、日期、试音编号或镜头清单硬编码成通用流程。
3. **工程契约**：`project.json` 是主时间线与素材/事实/音轨的共同来源；`state.json` 管执行状态，`costs.json` 管付费意图。三个文件职责分开，不维护第二份计时器。
4. **本地工具**：标准库 Python + FFmpeg。检查声明、探测实际媒体、输出字幕、按明确包络混音、按帧数渲染、审核最终编码。除 `voice` 命令把旁白文本发给已授权的 TTS 供应商外，原数据不上传；`voice` 每段请求前必须在账本预留预算。

## 模块

| 模块 | 职责 |
|---|---|
| `core.py` | 工程读写、规范计时、媒体探测、预检 |
| `captions.py` | 上下两语独立锚点与 SRT/ASS |
| `audio.py` | 已有 cue 的包络/淡化/叠加、二遍响度测量 |
| `render.py` | 真实视频/照片构图、连续相邻转场、精确帧数缓存；中间文件无损，最终导出只压缩一次 |
| `qa.py` | 导出完整解码、技术与响度检查、审阅帧 |
| `costs.py` | POSIX 单写账本、预留与结算；不调用供应商 |
| `tts.py` | MiniMax T2A 适配：地区探测、仅旁白、账本预留/结算、请求指纹缓存；密钥只读环境变量/私有文件 |
| `video.py` | 统一 CLI，无 Python 第三方运行依赖 |

## 成熟技术与来源

- [FFmpeg](https://ffmpeg.org/) 提供稳定的编码、滤镜、混音与测量；[许可证](https://ffmpeg.org/legal.html) 取决于实际构建。本仓库不分发其二进制、不抄其源码。
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) 是可选授权下载工具；使用其接口而非私有签名解析。源码和不同发行包许可证可能不同，按实际使用包核对。
- HyperFrames/Remotion 是可选精确图形/动画能力，NLE 是可选复杂剪辑能力；默认实拍片不引入无关完整平台。
- 规范与计时经验来自已完成并经用户认可的真实素材制作；新代码是独立通用实现。仓库不含接受影片的素材、私人路径、账户配置、人物音色文件或参考视频截图。

当前发布是工作流基础，不是带全部供应商集成的商业 SaaS。新工具应通过现有契约接入；不能偷偷换用 AI 镜头、扩大外传、放宽画质或丢掉原声/字幕能力。未来适配器与版本迁移见 [roadmap.md](roadmap.md)。
