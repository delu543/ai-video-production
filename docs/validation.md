# 验证范围与验收案例

## 自动测试

执行 `python3 -m unittest discover -s tests -v`。

单元测试覆盖：全局帧轴、双相邻转场对短镜头的约束、镜头关系与直接切理由、低有效分辨率、同源改名规避复用、源越界、未核查事实、字幕重叠/控制字符、显式单语与默认双语合同、可配置字幕锚点与画外拒绝、静态图开关不能放行生成视频、生成配乐拒绝与配音保留、禁用生成视觉/测试素材、发布许可门、路径越界与 symlink、预算/重复收费/未知状态、初始化保护、安装的幂等与本地改动保护。

集成测试用本机 FFmpeg 生成横屏、竖屏、照片和音频测试信号，再实际运行预检→有包络的二遍混音→中上英下字幕→连续两个淡化→全片编码→完整解码/响度/帧数检查→审阅帧。全片 3.9 秒、117 帧。替换右侧源文件后验证左右转场缓存都失效。合成夹具仅测试技术，默认生产门禁止它们。

没有 FFmpeg 时本地可跳过集成测试并明确说明；CI 设置 `REQUIRE_MEDIA_TESTS=1`，不允许跳过。实际支持的环境记录在本次发行验证信息中；不同 FFmpeg/字体版本必须重新跑相关测试。

## Skill 行为审阅用例

这些是可复用的实际制作验收用例，**不是已经自动执行的 Agent 评测**。审阅者对照 Skill 与对应规范检查是否指导正确行为；真正的跨题材成片还需要实际使用。

| 简短需求 | 应执行的行为 | 应避免的行为 |
|---|---|---|
| 做一支历史片，具体人物、年份和机制 | 研究主因果线，建事实底稿和对应档案 | 年表朗读、宏大口号替代机制 |
| 产品刚发布，更新到今天 | 查真实版本/日期/具体演示，核对截止时区 | 首页或 Logo 代替发布内容，编未来节点 |
| 面向年轻人的英文科普 | 自然青年试音、目标语言发音，中上英下可配置 | 电台腔、轻佻模仿、机械直译 |
| 先给几个 10 秒声音样本 | 同段同响度，预算内候选与精调 | 提前付费生成整片 |
| 素材质量不足 | 找原片/其他馆藏/照片，按裁后像素检查 | 下载缩略图、超分冒充原生高清 |
| 镜头关系突然跳，配乐情绪错 | 先修关系/桥接，再选切法；重排音色情绪和乐句 | 每个硬切加淡化、只统一减 BGM 音量 |
| 原声引语有价值 | 核对真实语境、原音同步、翻译、退让窗口 | AI 假扮历史人物或断章取义 |
| 付费调用超时或预算不足 | 查原任务，保留预留；继续免费工作 | 自动重复收费、改供应商躲开费用门 |
| 已接受画面，只换人声 | 保留接受内容，按新语音局部重对齐 | 整片无理由推倒重做 |
| 视频是4K但有随拍感 | 检查构图、用光、运动、风格与有效细节，拓展专业来源 | 只看像素数、加调色后直接通过 |
| 珍贵原始讲话仅标清 | 找较好原版，核对身份/日期/语境，按实际显示效果保内容 | 全部淘汰或宣称放大增加原生细节 |
| 有画面与名曲参考的完整脚本，要求真实素材 | 保留主线、核查事实与总时长，提取意图，找相近实拍/照片/授权配乐 | 自动生成漂浮镜头、取商业原录音，或强制后续题材使用同一配色 |
| BGM稍小但起伏不对 | 按实际选段校准，安排乐句/织体/呼吸，和镜头一起调整；密集旁白优先 | 只调一个总增益，或把全片音乐压到没有存在感 |
| 总时长正常但帧率不均 | 检查完整帧数/PTS与跨格式边界，追查输入规范和缓冲滤镜 | 只看平均帧率，靠冻帧补齐后宣称通过 |
| PCM峰值通过但最终AAC超标 | 修最终编码余量，保留画面、复测实际文件 | 重配整片声音、用PCM报告代替最终文件 |

## 新增行为审阅用例

| 简短需求 | 应执行的行为 | 应避免的行为 |
|---|---|---|
| 数据说明需要图片且真实材料无法表达，用户允许生图 | 先算/核查，生成有准确文字数字与关系的说明图，完整质感与假设/AI标注，保留提示与许可 | 生成无文字室内概念照、用模型当计算器或冒充银行文件 |
| 比例标签正确但图形长度不符 | 核对图形几何与实际比例，修正并重新检查最终图 | 只检查文字后放行 |
| 表格滚动截图有半行或半个数值 | 实际行高吸附、完整分页或重选停点，检查最终画幅与动效全阶段 | 用蒙版遮住半字后宣称排版通过 |
| 希望转场与数据更精良 | 按逻辑选择少量匹配/柔焦/声桥，条件→关系→结果渐次展开，保留阅读时间 | 无关镜头堆特效、闪现整屏数据或虚假中间数值 |

## 完成声明

安装校验、文档审计、工具测试、实际客户端发现、真实成片审阅、用户验收分别记录。CI 通过只证明受测的技术契约。它不证明声线自然、素材真的匹配、版权判断正确或“世界级”质感。

本地实际发行检查使用 Python 3.9 / FFmpeg 7.1 / FFprobe 4.4.1；仓库 CI 使用 Python 3.9 与 3.12、固定 Ubuntu 24.04 的 FFmpeg 和 Noto CJK 字体。Actions 固定官方发行的提交 SHA，使用 Node 24，并不在工作区保留 Git 凭证。具体远端运行结果以 [Actions](https://github.com/delu543/ai-video-production/actions) 为准，不把配置存在说成已通过。
