# 后续迭代

## 0.1.0 已提供

通用 Skill、完整分类规范、来源检索地图、工程模板、本地预检/字幕/混音/帧数剪辑/导出审计、付费预留、保护安装、回归测试与 CI。

## 由真实制作决定优先级

| 方向 | 目标 | 验收证据 |
|---|---|---|
| 供应商适配 | 经授权的 TTS/ASR 接口、回调、计费单位与状态恢复（0.2.0 已接入 MiniMax T2A；下一步：异步长文本、ASR 对齐） | 沙盒/预算内实际任务、超时查证、局部修正不重复收费 |
| 素材工具 | 统一授权下载、许可证证明、条目元数据与最高质量版本探测 | 多来源真实样本，缺权限不绕过，低清预览淘汰 |
| 音画辅助 QA | 对齐证据与段落、定位错画/重复/突兀边界 | 标注真实案例的召回/误报与人工复核，不能仅用模型自评 |
| 更丰富剪辑 | 保内容照片运动、匹配切、HDR 转换与关键帧构图 | 相邻转场/字幕/UI 空间和色彩的实际动态预览 |
| 音乐辅助 | 显式乐句、主题再现、可检查的声桥/duck 包络 | 实际听感审阅，改善音乐情绪而非只满足响度 |
| 跨题材验证 | 历史、科学、品牌等不同内容 | 新项目完整交付与用户反馈，限制不适用规则的范围 |

迭代不是越多规则越好。每次新增都回答“哪类真实问题、在哪一层解决、怎样确认没有损失有效能力”，再调整规范、工具、模板和版本。
